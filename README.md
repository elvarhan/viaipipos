# viaipipos (NusaPOS Ultimate v2.0) 🚀

Sistem Kasir & Restoran Multi Cabang Modern berbasis Web (React + Vite & Vanilla CSS) dengan tema Clean White & Emerald Green.

---

## ✨ Fitur Utama
1. **POS Kasir Digital**: Dine In vs Take Away, Manajemen Meja, Diskon & PPN 10%, Simpan Keranjang (*Hold Cart*), Struk Termal.
2. **📱 Pemesanan Mandiri Pelanggan (QR Self-Order)**: Pelanggan scan QR Code meja ➔ Pilih menu & catatan ➔ Konfirmasi kasir.
3. **🍳 Kitchen Display System (KDS)**: Monitor pesanan stasiun dapur real-time.
4. **☕ Bar Display System (BDS)**: Monitor pesanan stasiun bar/minuman real-time.
5. **🏢 Manajemen Multi-Cabang**: Pengaturan cabang pusat, manager PJ, alamat & status operasional.
6. **🪑 Manajemen Meja & QR Barcode 2D**: Visual grid meja reguler & VIP dengan cetak QR scannable A4.
7. **📊 Dashboard Analitik**: 4 KPI utama, grafik penjualan, top 5 menu terlaris, riwayat transaksi & refund.
8. **💵 Kalkulator Kembalian Otomatis**: Input nominal uang tunai diterima & kembalian terhitung real-time.

---

## 🛠️ Cara Menjalankan Projek

```bash
# 1. Install Dependencies
npm install

# 2. Jalankan Server Dev Lokal
npm run dev

# 3. Build untuk Produksi
npm run build
```
